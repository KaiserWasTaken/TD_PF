# Diccionario de datos

| Campo | Descripcion |
|---|---|
| `fecha_hora` | Fecha y hora local del siniestro |
| `tipo_siniestro` | Colision, atropellamiento, caida de ciclista u otro |
| `tipo_usuario` | Peaton, ciclista, motociclista, automovilista u otro |
| `gravedad` | Solo danos, herido o muerto |
| `latitud`, `longitud` | Coordenadas WGS84 |
| `calidad_geo` | Calidad de la coordenada |
| `fuente` | Origen trazable del registro |
